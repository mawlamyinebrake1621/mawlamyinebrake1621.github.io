🧭 What Is recontrail?

Think of recontrail as a patient assistant for photogrammetry, the craft of measuring and rebuilding real objects from pictures. You give it a set of photos taken around a subject, a statue, a building, a piece of furniture, or a small object on a table, and it works out where the camera must have been standing for each shot. From that understanding it grows a cloud of points, then a surface, and then a set of files you can open and explore.

The name says a lot about the design. The word trail hints at the path the camera took around your subject, and recon is short for reconstruction. Everything happens locally. Your photos never leave your machine, and the results are stored in a plain folder you can copy, back up, or hand to a colleague on a USB stick.

Because the program sticks to the central processor rather than a gaming graphics card, it works on ordinary laptops and office desktops. It may take longer than a cloud service, but it is dependable, repeatable, and completely private.

✨ What You Can Do With It

  • Check your photos before you commit. The first stage reviews sharpness, exposure, and overlap, then warns you if a shot is blurry or if there is a gap in coverage. Fixing a bad photo set early saves hours.
  • Recover the camera trail. The software estimates where each camera stood and which way it pointed, producing a sparse skeleton of your scene. You can watch this skeleton fill in as it grows.
  • Build calibrated stereo. Once the cameras are known, recontrail computes depth for pairs of images and turns those depth measurements into dense geometry.
  • Generate surfaces and points. The finished pass produces a mesh and a point cloud that open in common free viewers.
  • Share offline reports. Each project can be exported as a self-contained interactive report, a single folder that opens in a browser with no internet connection and no installation on the other person's machine.

💡 Why People Choose It

Most reconstruction tools assume you have a powerful GPU and a fast connection. recontrail assumes the opposite. It is built for researchers, students, hobbyists, surveyors, and anyone who needs results that can be reproduced later on exactly the same machine with exactly the same inputs.

  • Private by default. No account, no upload, no telemetry.
  • Runs on a CPU. A modern laptop with a normal processor is enough.

  • Reproducible. The same photos and settings produce the same result, which matters when you write up findings.

🖥️ Before You Begin

You do not need to install anything else first. A few simple preparations will make your first run smooth:

  • A Windows 10 or Windows 11 computer with a 64-bit processor.
  • At least 8 GB of memory for small projects, and more if you plan to process hundreds of photos.
  • About 5 GB of free disk space for the program and your first project folder.
  • A folder of photos shot with plenty of overlap. Slow, steady, circular movement around the subject works best.

If you are unsure whether your photos are suitable, that is exactly what the first inspection stage is for. It will tell you honestly.

🚀 Your First Project, Step by Step

  1. Create a project folder. Make a new folder somewhere simple, such as Documents or your Desktop. This is where recontrail will write everything it produces.
  2. Put your photos inside. Copy the images you want to use into that folder. Around thirty to eighty photos is a comfortable starting point.
  3. Start the program. Open the recontrail folder, launch the application, and wait a moment for the main window to appear.
  4. Point it at your photos. Choose the folder you created and let the quality check run. Read the summary it shows you.
  5. Run the reconstruction. Start the camera and geometry stage. This is the slow part; expect it to take a while and leave the computer plugged in.
  6. Explore and export. When it finishes, open the interactive report, spin the model around, then export a copy to share.

You can stop after any stage. The folder keeps whatever has been completed, so a long run never has to start from scratch.

📁 What You End Up With

At the end of a successful run your project folder will contain a set of results that are easy to identify: a quality report describing the input photos, a camera file listing where each photo was taken from, a sparse cloud of points showing the rough shape of the scene, a dense cloud and mesh showing the fine detail, and an interactive report you can open in any browser. Each of these is a normal file on your disk. Nothing is locked inside a database or hidden in a hidden system directory.

🛠️ Common Questions

Do I need a fast graphics card? No. recontrail deliberately uses the processor instead, so it runs on ordinary hardware.

Will my photos be sent anywhere? No. Every stage happens locally and no data leaves the machine.

Why is it slow? Careful geometry work on a processor takes time. A few dozen photos may take several minutes; a few hundred may take hours. Let it run.

What if the quality check complains? Delete or retake the flagged photos and run the check again. Small fixes make a large difference.

Can I move a project to another computer? Yes. Copy the whole project folder. The results travel with it.

Does the shared report need internet? No. The exported report is fully offline and self-contained.

Can I use a video instead of photos? You can extract still frames from a video with any common tool, then treat those frames as your photo set.
